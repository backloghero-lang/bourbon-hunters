# Bourbon Hunters

Aplikacja do odkrywania, skanowania i kolekcjonowania bourbonów i whisky.

- **Wersja web:** https://backloghero-lang.github.io/bourbon-hunters/
- **Pobierz na Androida (demo):** https://backloghero-lang.github.io/bourbon-hunters/download.html

To repozytorium zawiera wyłącznie opublikowaną wersję strony i aplikacji demo.
Kod źródłowy jest prywatny. Wszelkie prawa zastrzeżone, zobacz [LICENSE](LICENSE).
